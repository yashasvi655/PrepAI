# PrepAI 🚀

AI-powered interview and exam preparation platform that helps users practice with AI-generated quizzes, analyze performance, and prepare smarter.

## Features

- 🔐 User Authentication (Login/Signup)
- 🤖 AI-generated quizzes
- 📄 Upload PDF notes and generate quizzes
- 📊 Performance analytics
- 📝 Quiz history tracking
- 🏆 Leaderboard system
- 🌙 Dark/Light mode support

## Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

### AI Integration
- Google Gemini AI
